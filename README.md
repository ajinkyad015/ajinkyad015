### [Fincite](https://github.com/ajinkyad015/fincite) — AI-Powered Financial Filing Research Assistant
> Evidence-grounded RAG system for querying Indian listed companies’ annual reports and investor presentations

Building an end-to-end financial research assistant that answers natural-language questions over company filings with verified financial values, page-level source citations, and confidence scores.

Designed a multi-agent `LangGraph` workflow that separates query planning, document retrieval, financial metric extraction, verification, and response synthesis. Includes a verification-and-retry mechanism that cross-checks extracted values against source statements and automatically re-runs retrieval when inconsistencies are detected.

`Python` `LangGraph` `FastAPI` `OpenAI / Qwen` `PostgreSQL` `pgvector` `React` `Docker`
